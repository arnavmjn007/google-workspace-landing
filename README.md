Google Workspace Landing Page Clone

A pixel-perfect recreation of the Google Workspace landing page. This project focuses on high-fidelity UI replication, responsive design, and interactive component architecture.

Live Demo: https://google-workspace-landingpage.vercel.app

🚀 Tech Stack

* Framework: [Next.js](https://nextjs.org/) (App Router)
* Styling: [Tailwind CSS](https://tailwindcss.com/)
* Icons & Assets: Custom SVGs and Optimized PNGs
* Deployment: [Vercel](https://vercel.com/)

✨ Key Features Replicated

* Interactive Feature Accordion: A custom-built list that manages active states to show/hide feature descriptions with the signature Google blue indicator.
* Solution Cards: Responsive grid layout featuring centered typography and high-fidelity image containers.
* Dynamic Icon Grid: A complex layout of Google Workspace apps, carefully aligned to match the original marketing materials.
* Sales Representative Section: Complex absolute positioning with radial background gradients and overlapping image assets.

🧠 Challenges & Learnings

Building this project provided several great learning opportunities:
1.  Pixel Perfection: Matching the exact spacing and brand colors (like Google Blue `#1A73E8`) across different screen sizes.
2.  Complex Layouts: Implementing the "rainbow" background behind the sales representative while ensuring it crops correctly on mobile.
3.  Deployment Configuration: Configuring Vercel to correctly identify the project root directory and framework presets during the build process.
